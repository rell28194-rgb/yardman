# YARDMAN — PRIVATE ASSET USE PERMISSION OVERRIDE

This file records the owner's current and controlling instruction for Yardman asset recovery and integration. It supersedes older language that described Beta 1 / Beta 2 material as "reference/inspiration only" where that wording conflicts with this directive.

## Project distribution context

Yardman is a private project. It is not being prepared for ordinary public distribution. Builds are intended for the owner and, where appropriate, the companies, studios, creators, communities, or connected rights-holders whose work is being used in the project.

## Permission scope stated by the owner

The owner states that every Beta source file provided for Yardman was obtained from the relevant companies, studios, creators, communities, or people connected to those rights-holders with permission for use in this private collaboration project.

Accordingly, authorized Beta 1 / Beta 2 material is not limited to cars, vehicle behavior, or visual inspiration. It may be directly recovered, converted, adapted, optimized, and integrated into the Godot production runtime whenever doing so improves Yardman.

This permission applies across asset and system categories, including where technically useful:

- complete vehicle meshes and submeshes;
- wheels, brakes, interiors, lights, dashboards, glass, materials, textures and LODs;
- vehicle audio, drivetrain-related audio, tire/road audio and driving-feedback assets;
- garage, vehicle-selection, menu, HUD, UI and presentation assets;
- buildings, architectural components, street furniture, roadside props and settlement assets;
- vegetation, foliage, terrain materials, rocks, cliffs, water, shoreline and atmosphere assets;
- character meshes, rigs, animations and related presentation material;
- environmental audio, ambience, effects, world-life presentation and other suitable content;
- any other useful authorized source material present in the Beta archives.

Direct reuse is allowed. An asset does not need to be redesigned merely to avoid looking recognizably derived from the authorized source. If a source asset already solves a problem well, using that asset recognizably can be desirable for this private collaboration project.

Toyota-branded vehicle material may be used directly under the owner's stated permission, including Toyota naming and branding where available and technically appropriate.

## Explicit exception: Porsche

Porsche is the current exception. Do not use Porsche-owned production assets, Porsche branding, model names, badges, logos, or other Porsche-specific protected material unless the owner later provides a new permission instruction.

For the current 992-class slot, retain an original fictional implementation that does not copy Porsche-owned production assets.

## Execution rule

Do not artificially restrict authorized Beta 1 / Beta 2 sources to "reference," "inspiration," "study," or "look-and-feel" use when direct reuse is more effective.

Agents should actively inspect, recover, convert, optimize, and integrate authorized material into Yardman's Godot runtime. Preserve provenance so source origin and transformations remain auditable, but provenance tracking is not a reason to avoid integration.

Use the strongest available authorized source when it materially improves the game. A CarX vehicle that already has strong geometry, materials, proportions, wheels, interior detail, or other useful components should be treated as a candidate for direct integration rather than automatically recreated from scratch. The same rule applies to non-vehicle content from other authorized Beta sources.

The decision test is technical and artistic fit, not fear of resemblance. Evaluate:

- quality;
- scale and coordinate fit;
- Godot compatibility;
- Android performance;
- Jamaica-specific suitability;
- LOD/material/shader requirements;
- whether the asset improves the final experience.

Do not reject an otherwise useful authorized asset simply because it is recognizable as work from a contributing studio or source project. Visible continuity with collaborating studios' work can be a positive feature of Yardman.

## Relationship to older checkpoints

Older inventory files may truthfully record what had not yet been copied or integrated at the time they were written. Keep those historical facts intact.

However, historical phrases such as "private reference/inspiration only," "no public repository media copied," or similar wording are not current prohibitions against direct use of authorized material in the private Yardman runtime.

This permission override controls future execution unless the owner explicitly changes it.
