# YARDMAN — PRIVATE ASSET USE PERMISSION OVERRIDE

This file records the owner's current and controlling instruction for Yardman asset recovery and integration. It supersedes older language that described Beta 1 / Beta 2 material as "reference/inspiration only" where that wording conflicts with this directive.

## Project distribution context

Yardman is a private project. It is not being prepared for ordinary public distribution. Builds are intended for the owner and, where appropriate, the studios / rights-holders whose work is being used in the project.

## Permission scope stated by the owner

The owner states that permission has been obtained to use the available source material in Yardman, including direct recovery, conversion, adaptation and runtime integration of useful assets and systems from the authorized source sets.

This includes the previously inventoried Beta 1 / Beta 2 material and Toyota-branded vehicle material. Toyota branding may be used directly under the owner's stated permission.

The explicit exception is Porsche material: do not use Porsche-owned assets, branding, model names, badges, logos or other Porsche-specific protected material unless the owner later provides a new permission instruction. For the current 992-class slot, retain an original fictional / parody implementation that does not copy Porsche-owned production assets.

## Execution rule

Do not restrict authorized Beta 1 / Beta 2 sources to visual inspiration when direct reuse is technically useful. Agents should actively inspect, recover, convert, optimize and integrate authorized material into the Godot production runtime, while preserving provenance so the source and transformation history remain auditable.

Prioritize source material according to project value, including:

- vehicle meshes, materials, wheels, interiors, lighting and presentation;
- vehicle audio and driving-feedback assets;
- garage, selection and UI assets / patterns;
- tropical buildings, props and roadside environment assets;
- foliage, terrain, water, shoreline and atmosphere assets;
- character / animation material where suitable;
- world-life and environmental presentation assets.

Do not copy material blindly. Technical fit, quality, scale, mobile performance, Jamaica-specific suitability and runtime integration still determine whether an authorized asset belongs in Yardman.

## Relationship to older checkpoints

Older inventory files may truthfully record what had *not yet been copied or integrated at the time they were written*. Keep those historical facts intact. However, historical phrases such as "private reference/inspiration only; no public repository media copied" are not a current prohibition against using authorized material in the private Yardman runtime.

This permission override controls future execution unless the owner explicitly changes it.
