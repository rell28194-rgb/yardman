# Playable traversal loop

The main scene starts in St. Mary by default and restores a valid prior save when present. Every parish has equal access through the travel selector, which uses the nearest source road point to its administrative-centre QA anchor. These anchors are not parish polygons and do not prove complete regional fidelity. Travel resets motion and waits for local collision, with the same world-coordinate and streaming model used during normal traversal.

The original vehicle now has a visible body, cabin, mirrors, bumpers, wheels, lights and plate. Its CharacterBody3D controller provides acceleration, reverse, braking, steering, gravity, floor snapping and ground-normal visual alignment. It is a kinematic traversal vehicle; tyre/suspension/damage fidelity remains unimplemented. A parked car keeps a double-precision canonical position and freezes physics when its collision tile unloads, even while the player is active elsewhere. The player can exit a stopped vehicle into a collision-tested side space, walk, sprint, look around and re-enter nearby. The chase/on-foot camera tests obstruction against local world collision.

Touch controls track independent finger IDs. Releasing one finger does not clear another; focus loss releases held controls. WASD/arrows move, E enters/exits, Shift sprints, F5 saves and R recovers to the selected parish. Performance, Balanced, Quality, Ultra and Custom change streaming radii, vegetation visibility, shadows and render scale. Custom exposes editable values. Existing vegetation retains a deterministic prefix when density changes. Proxies are original art, not claims of surveyed vegetation.

Saves record EPSG:3448 easting/northing, uncompressed elevation, actor heading, occupancy, parish, quality/custom settings, odometer and time of day. Node3D coordinates are never persistent truth. Writes use a checked temporary file, rotation to a backup and rename. SHA-256 checks the exact stored JSON string, avoiding the integer-to-float round-trip bug in Godot JSON parsing. Corrupt primaries recover the previous validated backup. Autosave and Android pause-save wait for collision readiness.

The gameplay test visits all fourteen parishes and verifies terrain contact; tests walking/driving, moving-vehicle exit rejection, distance-limited entry, coordinate stability under rebasing, save/load and corrupt-save recovery, non-finite coordinate rejection, independent touch input and quality selection. Passing these tests is not evidence of on-device frame rate, long-duration thermal stability, finished art or a complete life-simulation game. NPCs, traffic, missions, businesses, economy, full animation, weather and sound remain to implement.
