# National roads

The compiler reads the complete Geofabrik Jamaica OSM PBF through PyOsmium, retaining actual OSM way IDs and node references. EPSG:4326 is transformed with PROJ into EPSG:3448. World X is easting minus the registered origin, Z is origin northing minus northing, and Y is uncompressed elevation. Geographic scalar values remain double precision. GeoJSON remains an explicit fallback; coordinate-derived fallback IDs must not be confused with true OSM IDs.

Topology is independent of rendered tiles. Shared OSM nodes split way curves into logical edges. Geometric crossings do not create intersections, preventing a bridge and the road below it from becoming accidentally connected. Edge IDs derive from source way and endpoint identities. An edit to intermediate curve geometry retains the edge identity when its endpoints remain unchanged. Metadata retains road class, width, surface, one-way direction including reverse one-way, speed tags, bridge, tunnel and layer. Missing speed limits remain unknown rather than being represented as surveyed facts.

Node and edge records are partitioned by the first two hexadecimal digits of SHA-1 of their string ID. Each partition is a JSON dictionary. Node records contain canonical positions and incident edge IDs; edge records contain directed endpoints, full canonical curves, length, metadata and touched tiles. This is a data addressing hash, not a security primitive. The runtime world database loads bounded graph partitions independently of visible meshes. Evicting a mesh or graph cache entry cannot delete a road's identity or connectivity.

The tile compiler computes shared, bounded miter cross-sections along each complete source way before splitting logical edges or clipping tiles. Adjacent segments share both sides of their joins instead of overlapping disconnected rectangles. Near reversals cannot produce unbounded triangular spikes; the maximum join extension is 1.6 times the half-width. Closed ways share their first/last join positions. The compiler then clips the entire ribbon, including width, to each tile rectangle. Areas do not overlap across neighboring tiles. Seam vertices and UV attributes are computed from the same global ribbon and quantized to one micrometre. Centerline traversal uses exact boundary splits; a road lying on a boundary has one centerline owner while its visible width is split between both sides. There are no duplicated full-width border ribbons.

Measured OSM `width` tags take priority, followed by OSM `lanes` with explicitly inferred lane widths, then individual-carriageway class estimates. A separate motorway carriageway is no longer painted as a 14 m whole highway. Metadata records lane count, the width source and whether markings are inferred. Lane/centre paint is conservative on major paved classes and omitted on unpaved/local roads. This is presentation, not a surveyed inventory of Jamaican road paint.

Road tile format 3 preserves fields 0–11: start X/Z, end X/Z, width, class, flags, edge ID, curve segment index, endpoint Y values, and polygon. Fields 12–17 add per-polygon UVs, inferred paint mode, lanes, source speed limit, and the start/end source-way stations of the logical edge. UV X is continuous source-way distance in metres; UV Y is signed lateral distance. Both survive national tile clipping and terrain-triangle subdivision. Edge bounds suppress crossed paint at graph junctions. Runtime normals follow the conformed terrain plane, asphalt uses derivative-filtered procedural grain, and a small stable source-way height offset prevents equal-depth intersection flicker. Road surfaces fade within 2.6 km by default rather than rendering over the coarse national overview. The camera near plane and resident fine-terrain radius must support the selected surface range.

The runtime indexes visible logical segments in occupied 128 m cells while incrementally preparing a tile. `road_surface_at(world_x, world_z)` returns found state, surface, source speed, width, distance, class and edge ID for local driving friction. `nearby_paths(world_x, world_z, radius=220)` returns canonical X/Z segment paths for the radar, deduplicated across terrain fragments and neighboring cells. Queries are bounded to loaded tiles, 512 m radius and 384 radar paths. The index is removed with its tile, independently of the persistent national road graph; it is not a replacement for graph topology.

Generated files and raw geodata remain outside Git. The manifest records source SHA-256, CRS, origin, bounds, all fourteen parish QA anchors, graph totals and data attribution. Compiler output is staged before replacing the previous dataset. OSM is a source requiring further validation; the coverage sentinels prove broad data presence, not that every road or parish boundary is accurate.

At the road-continuity checkpoint, the real source generated 59,389 ways, 120,231 logical edges, 101,484 nodes, 712 visible road tiles and 7,337 centerline boundary crossings. The new terrain layer replaces unmeasured-flat road elevation with registered DEM samples. Ribbons are additionally subdivided onto terrain triangles so the render surface follows physics across its entire width. Bridge/tunnel flags are retained but do not invent surveyed deck/portal heights. See TERRAIN.md for source resolution and limitations.
